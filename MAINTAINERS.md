# Maintainers and contact routes

This page is the single place other documents point to for contact routes.
When a route changes, it changes here.

## Current routes

| Purpose | Route |
|---|---|
| Bugs, questions, feedback | This repository's [issues](../../issues) |
| Security disclosure | GitHub private vulnerability reporting (Security tab) |
| Code of conduct reports | Email the Collective's current PMO contact point: josephine.chu@dalberg.com |
| Everything else | Email the Collective's current PMO contact point: josephine.chu@dalberg.com |

## Current maintainers

During the Collective's research phase (through November 2026), this
repository is maintained by the project team of the AI for Accessibility
Collective. Individual code contributions are recorded in the repository
history; the citation entry (CITATION.cff) currently credits the
Collective as a whole.

## After the research phase

Maintainer roles beyond the research phase — including custodianship of
the repositories, review of outside contributions, and operation of any
hosted services — are being defined. Project governance is recorded in
[MAINTAINERS.md in the toolkit repository](https://github.com/AI-for-Accessibility-Collective/AI-for-Accessibility-Toolkit/blob/main/MAINTAINERS.md),
whose contact routes this file mirrors.
