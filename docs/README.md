# Docs

Documentation for the AI for Accessibility extensions. Links are relative to
this directory.

The toolkit core's documentation (architecture, the tools-layer API, the hosted
service, design docs) lives in the toolkit repository: <https://github.com/AI-for-Accessibility-Collective/AI-for-Accessibility-Toolkit>.

## For people using the extensions

- [GETTING-STARTED.md](GETTING-STARTED.md) — Plain-language guide: install, first success, updating, removing.
- [COSTS.md](COSTS.md) — What is free, what can cost money, and how the API key works.
- [DATA-AND-PRIVACY.md](DATA-AND-PRIVACY.md) — What is stored, what is sent, what is remembered, in plain words.
- [WHAT-TO-EXPECT.md](WHAT-TO-EXPECT.md) — Where it works, where it fails, named risks and what we do about them.
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md) — Common problems and fixes (user problems first, developer material after).
